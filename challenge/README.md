# Fix My Code Challenge

This project is part of the Holberton School curriculum.

The goal of the project is to debug and fix existing code rather than rewrite it from scratch.

## Tasks

* **0. FizzBuzz** — Fix the FizzBuzz implementation in Python.
* **1. Print square** — Fix the JavaScript implementation.
* **2. Sort** — Fix the Ruby implementation.
* **3. User** — Fix the Python implementation.
* **4. Delete dnodeint** — Fix the doubly linked list implementation.

## Requirements

* All files must end with a new line.
* The existing code should be fixed rather than completely rewritten.
* The solutions are developed and tested on Ubuntu 20.04 LTS.
